# Nebula OS

ブラウザの単一タブ内で動作する、静的ファイルのみで構成されたデスクトップ環境です。フレームワークやビルドツール、バックエンドサーバーを一切使わず、HTML・CSS・JavaScript の標準 API だけで作られています。

バージョン: 1.0.0  
作者: hajikkoyure  
デモ: https://hajikko-yure.github.io/nebula-os/

---

## 動かし方

### 1. ブラウザで直接開く（オンライン）

GitHub Pages で公開しているため、以下のリンクからそのまま試せます。

- **デモサイト**: https://hajikko-yure.github.io/nebula-os/

### 2. ローカル環境で動かす

リポジトリを取得後、ローカルサーバーを起動するか、`index.html` を直接ブラウザで開きます。

```bash
git clone https://github.com/hajikko-yure/nebula-os.git
cd nebula-os
```

ブラウザによっては `file://` 直開きで一部のセキュリティ制約（localStorage や Web Audio の挙動など）が働く場合があるため、ローカルサーバー経由での閲覧を推奨します。

```bash
# Python を使う場合
python -m http.server 8000

# Node.js を使う場合
npx serve .
```

起動後、`http://localhost:8000` にアクセスしてください。

## 収録アプリ

標準で 12 種類のアプリケーションを同梱しています。

| アプリ名 | 概要 |
| :--- | :--- |
| **Files** | 仮想ファイルシステムを操作するファイルマネージャ。ドラッグ移動、右クリック操作、ファイル作成に対応 |
| **Terminal** | `nebula-sh`。`ls`, `cat`, `tree`, `neofetch`, `df`, `theme` などの基本コマンドを実行可能 |
| **Notepad** | プレーンテキストエディタ。仮想ファイルシステムへの保存・読み込みに対応 |
| **Settings** | テーマ（Dark / Light）、アクセントカラー、壁紙、ドックの挙動、キーバインドの確認 |
| **Calculator** | 浮動小数点演算とキーボード入力に対応した電卓 |
| **Music** | Web Audio API を用いたプロシージャル・シンセサイザー。リアルタイム波形描画付き |
| **Photos** | アルゴリズムによるプロシージャル画像生成とビューア |
| **Browser** | サンドボックス化された iframe による Web サイト閲覧（オフライン用クイックリンク付き） |
| **Weather** | 地点選択とシミュレートされた気象データ表示 |
| **Minesweeper** | 初級・中級・上級の 3 段階を備えたマインスイーパー |
| **Clock** | 世界時計、ストップウォッチ、タイマー機能 |
| **Mail** | デスクトップ通知と連動した擬似メールクライアント |

## ウィンドウシステムと操作体系

デスクトップの操作感は、一般的なデスクトップ OS の作法に寄せています。

- **ウィンドウスナップ**: ウィンドウを画面上端へドラッグすると全画面化、左右端へ寄せると画面半分のサイズに吸着します。また、最大化ボタンのホバーで分割候補を選択できます。
- **タスク切り替え**: `Alt + Tab` で実行中のアプリを一覧し、キーを離すことでアクティブウィンドウを切り替えます。
- **ランチャー**: `Super`（Windows キー）または画面左下のスタートボタンから、全アプリの検索と起動が行えます。
- **コンテキストメニュー**: デスクトップやファイル、タスクバーの右クリックから各種操作を呼び出せます。

## 設計方針と内部構造

### 1. 依存関係なしの素の JavaScript
外部 npm パッケージや UI ライブラリに依存していません。各アプリは `scripts/apps/` 配下に独立した IIFE として記述され、`OS.apps.register` を介してシステムに登録されます。

### 2. 仮想ファイルシステム (VFS)
ファイルやディレクトリのツリー構造はメモリ上に構築され、変更があるたびに `localStorage` へシリアライズされます。ブラウザをリロードしても作成したテキストや設定内容は維持されます。

### 3. バックアップとリストア
設定値および仮想ファイルシステム全体のデータは、単一の JSON ファイルとしてエクスポートできます。別の端末や別ブラウザでも、エクスポートした JSON を読み込むことで作業環境を復元できます。

## 既知の制限事項

- **Web 閲覧の制限**: Browser アプリは `iframe` を使ってページを読み込みます。対象サイトが `X-Frame-Options` や CSP（コンテンツセキュリティポリシー）で埋め込みを禁止している場合、ブラウザ側で表示がブロックされます。その場合は「新しいタブで開く」ボタンで外部ブラウザに引き渡す挙動にしています。
- **保存容量の制約**: すべての永続化データはブラウザの `localStorage` に依存するため、保存可能なファイルサイズの上限はおよそ 5MB 前後となります。大きな画像やバイナリの保存には向いていません。

## プライバシーと安全性

本プロジェクトは完全にクライアントサイドのみで完結しており、外部サーバーへのテレメトリ送信やデータ収集は一切行いません。コードをコミット・プッシュする前には、意図しないローカルパスやプライベート IP の混入を防ぐ監査スクリプトを実行しています。

```bash
python tools/check_privacy.py
```
